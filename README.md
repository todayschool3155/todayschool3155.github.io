# 오늘학원 시간표 · 업무일지

휴대폰과 PC에서 쓰는 학원 시간표·업무일지 웹앱입니다. PC를 켜 두지 않아도 24시간 동작합니다.

- **화면(웹페이지)**: GitHub Pages — 무료 호스팅, 주소 예: `https://아이디.github.io/today/`
- **데이터(DB·로그인)**: Supabase — 무료 PostgreSQL 데이터베이스(서울 리전)
- 개인정보(학생 이름 등)는 **Supabase에만** 저장되고, GitHub에는 올라가지 않습니다.

```
[휴대폰/PC 브라우저] ──▶ GitHub Pages (화면 파일만)
         │
         └──── 로그인·조회·저장 ──▶ Supabase (DB, 로그인 검사, 로그 기록)
```

## 주요 기능

| 기능 | 내용 |
|---|---|
| 홈 (대시보드) | 오늘 수업, 밀린 업무일지, 이번 달 출석률, 주의 학생(결석 3회+), 최근 테스트, 최근 변경, 예정 시간표·휴원일을 한 화면에 |
| 미작성 알림 | 최근 14일 중 수업이 있었는데 일지를 저장하지 않은 날 → 메뉴 빨간 숫자 배지 + 선생님 화면 상단 알림(바로 작성 링크). 휴원일 제외 |
| 성적 | 금요 테스트 등 입력 (항목 자유: 듣기·문법 / 개별·공통 …), 수업 단위로 응시 학생 불러오기, 평균 자동, A4 인쇄. "병결" 등 글자는 평균에서 제외 |
| 학생 카드 | 학생 이름을 누르면 모든 선생님의 수업 기록·출결·성적 추이 그래프를 한 화면에 (진도 인수인계·상담용) |
| 통계 (관리자) | 월별 학생 출결(출석률·결석·미기록), 선생님별 일지 작성/미작성, 월간 학습 리포트 인쇄 (학생마다 A4 1장) |
| 휴원일 | 관리 화면에서 등록(기간 입력 가능). 알림·통계에서 제외 |
| 로그인 | 아이디·비밀번호 있는 사람만 접속. 관리자 `admin`, 모든 초기 비밀번호 `today1234`. 5회 틀리면 10분 잠금 |
| 시간표 보기 | 요일별 / 선생님별 / 주간 전체. 학생 이름 검색 → 그 학생의 주간 수업 표시. 휴대폰 화면에 맞춤 |
| 시간표 편집 (관리자) | 칸을 눌러 학생 추가·삭제·순서 변경, PC에서는 끌어서 이동(Ctrl+끌기 = 복사), "다른 요일에도 적용" |
| 시간표 버전 | 각 시간표는 **적용 시작일**을 가짐. 10/5부터 바뀌는 시간표를 미리 만들어 둘 수 있고 과거 시간표도 보존 |
| 신규·퇴원 | 학생 등록 → 배치 화면에서 요일·교시 체크. 퇴원 시 퇴원일부터 시간표에서 자동 제거. **퇴원생 기록은 영구 보관** (기록이 있는 학생은 삭제 불가) |
| 선생님 퇴사 | 퇴사 처리 시 담당 수업을 다른 선생님에게 넘기거나 비움(퇴사일부터). 계정 사용 중지·삭제해도 **일지·시간표·성적·로그는 영구 보관**, 업무일지에서 "퇴사한 선생님"으로 조회 |
| 업무일지 | 날짜+선생님을 고르면 **그 날짜의 시간표로 학생 목록이 자동 생성**. 출결·진도·숙제·특이사항·공지·총평, 자동 저장, 지난 진도 힌트 |
| 작성 현황 (관리자) | 이번 주 선생님별 작성완료/작성중/미작성 한눈에 |
| A4 인쇄 | 업무일지: 날짜·선생님마다 A4 1장 (기간 지정 일괄 인쇄, 빈 양식 인쇄 가능). 시간표: 주간 가로 1장 / 요일별 / 선생님별 |
| 보관 | 업무일지 1년 이상 보관, 월별 엑셀 내보내기, 전체 백업(JSON), 1년 지난 일지 정리 버튼 |
| 로그 | 로그인·로그인 실패·시간표 변경 내용·학생 등록/퇴원·일지 저장 등 모두 기록, 기간·종류별 조회, CSV 저장 (400일 보관) |
| 권한 | 관리자: 전체. 선생님: 시간표 보기 + **본인 담당 칸만** 학생 추가/삭제, **본인 일지만** 작성, 신규 학생 등록 (퇴원 처리는 관리자) — 서버에서 강제 |

**"시간표를 바꾸면 업무일지가 자동으로 바뀌는" 원리**: 업무일지는 학생 목록을 따로 저장하지 않고, 열 때마다 "그 날짜에 적용되는 시간표"에서 학생을 가져옵니다. 이미 적어 둔 기록은 학생별로 저장되어 있어서, 시간표에서 빠진 학생의 기록도 "시간표 외"로 남아 사라지지 않습니다.

## 설치 (처음 한 번, 약 30분)

### 1단계. Supabase(데이터베이스) 만들기

1. <https://supabase.com> 가입 (GitHub 계정으로 로그인 가능) → **New project**
   - Name: `today` / Database Password: 아무 강한 비밀번호(따로 보관) / Region: **Northeast Asia (Seoul)**
2. 프로젝트가 만들어지면 왼쪽 메뉴 **SQL Editor** → **New query**
3. 이 폴더의 `supabase/schema.sql` 내용을 전부 붙여넣고 **Run** → "Success" 확인
4. 새 쿼리를 열어 `supabase/seed.sql` 내용을 붙여넣고 **Run**
   - 엑셀에서 옮긴 선생님 5명, 학생 70명, 2026-08-30 시간표가 들어갑니다.
   - `seed.sql`은 이 PC에만 있는 파일입니다(학생 이름 포함, GitHub에 올라가지 않음).
5. 왼쪽 아래 **Project Settings → API**(또는 **API Keys**)에서 두 값을 복사
   - **Project URL** (예: `https://abcdefgh.supabase.co`)
   - **anon public** 키 또는 **Publishable key** (`sb_publishable_...`) — ⚠ `service_role`/`secret` 키는 절대 사용하지 마세요.
6. `js/config.js`를 메모장으로 열어 붙여넣기:
   ```js
   export const SUPABASE_URL = 'https://abcdefgh.supabase.co';
   export const SUPABASE_KEY = 'sb_publishable_xxxxxxxx';
   ```
   (이 키는 공개돼도 안전합니다. 데이터는 로그인 토큰을 검사하는 함수로만 접근됩니다.)

### 2단계. GitHub에 올리고 웹페이지로 공개

1. <https://github.com> 가입 → 오른쪽 위 **+ → New repository**
   - Repository name: `today` / **Public** 선택 (무료 GitHub Pages는 Public 저장소만 가능 — 코드만 공개되고 학생 데이터는 없습니다)
2. 이 폴더를 올리기 — 둘 중 편한 방법:
   - **방법 A (쉬움)**: [GitHub Desktop](https://desktop.github.com) 설치 → File → Add local repository → 이 폴더 선택 → Publish repository
   - **방법 B (명령어)**: 이 폴더에서
     ```bash
     git add .
     git commit -m "오늘학원 시간표·업무일지"
     git branch -M main
     git remote add origin https://github.com/아이디/today.git
     git push -u origin main
     ```
   - 올리기 전 확인: `data/`, `supabase/seed.sql`, `*.xlsx` 는 `.gitignore` 때문에 **올라가지 않아야 정상**입니다.
3. 저장소 **Settings → Pages** → Source: **Deploy from a branch**, Branch: **main**, 폴더 **/(root)** → Save
4. 1~2분 뒤 `https://아이디.github.io/today/` 접속 → `admin` / `today1234` 로그인 → **바로 비밀번호 변경**

### 3단계. (권장) 방학 중 일시정지 방지

Supabase 무료 플랜은 **7일간 아무도 접속하지 않으면 일시정지**됩니다(대시보드에서 Restore 누르면 복구, 데이터는 유지).
방학 대비로 자동 깨우기를 켜 두세요:
- GitHub 저장소 **Settings → Secrets and variables → Actions → New repository secret**
  - `SUPABASE_URL` = Project URL, `SUPABASE_KEY` = anon/publishable 키
- 이후 `.github/workflows/keepalive.yml`이 3일마다 서버를 한 번 호출합니다. (Actions 탭에서 "Run workflow"로 바로 시험 가능)

### 4단계. 휴대폰 홈 화면에 추가

- 아이폰(Safari): 공유 버튼 → **홈 화면에 추가**
- 안드로이드(Chrome): ⋮ 메뉴 → **홈 화면에 추가** / 앱 설치

## 자주 하는 일

**신규 학생**
학생 → `+ 신규 학생` → 저장 후 "배치하기" → 요일·교시·선생님 칸 체크 → 적용 시작일 선택 → 저장.
(시간표 편집 화면에서 칸에 없는 이름을 입력해도 바로 등록할 수 있습니다.)

**퇴원**
학생 → `퇴원` → 퇴원일 입력 → "시간표에서 제거" 체크 → 퇴원 처리.
퇴원일부터의 시간표·업무일지에서 자동으로 빠지고, 그 전 일지·성적은 그대로 남습니다.
학생 목록에서 "퇴원"을 고르면 퇴원생과 학생 카드(지난 기록)를 볼 수 있고, `재등록`으로 되돌릴 수 있습니다.
"잘못 등록한 학생 삭제"는 기록이 하나도 없을 때만 됩니다.

**선생님 퇴사 · 계정 삭제**
관리 → 선생님 → `퇴사 처리` → 퇴사일, 담당 수업(다른 선생님에게 넘기기 / 비우기 / 그대로) 선택.
- 퇴사일부터의 시간표에만 적용되고, 그 전 시간표·일지는 그대로입니다. 로그인 계정은 자동으로 사용 중지됩니다.
- 관리 → 로그인 계정 → `삭제`: 아이디만 지워지고 그 선생님의 일지·성적·로그는 보관됩니다.
- 지난 기록 보기: 업무일지 → 선생님 선택 → "퇴사한 선생님" / 통계에도 그 달 기록이 있으면 표시됩니다.
- 다시 오시면 `복직`. 선생님 정보 자체는 삭제할 수 없게 되어 있어 기록이 실수로 지워지지 않습니다.

**시간표 변경**
- 오늘부터 바로 바꾸기: 시간표 → `편집` → 칸 수정 → `이 버전에 저장`
- 다음 주부터 바꾸기: `편집` → 수정 → `새 적용일로 저장` → 날짜 지정
- 미래 버전이 있으면 저장할 때 "이후 버전에도 같은 변경 적용"을 선택할 수 있습니다.
- `버전 관리`에서 적용일 변경·복사·삭제

**업무일지**
- 학생 이름 옆 ✕ → "오늘만 제외" 또는 "시간표에서 빼기(이 날부터 매주)"
- `+ 보강/추가 학생` → "오늘만 추가" 또는 "시간표에 추가(이 날부터 매주)", 없는 학생은 바로 신규 등록
업무일지 → 날짜 선택(◀ ▶ 로 평일 이동) → 출결 버튼·진도·숙제·특이사항 입력 → 자동 저장 → 다 쓰면 "작성 완료" 체크.
- 진도 칸이 비었을 때 → (오른쪽 화살표) 키: 지난 수업 진도 불러오기
- `+ 보강/추가 학생`: 시간표에 없는 학생을 그날만 추가

**인쇄 (A4)**
- 업무일지 → `인쇄` → 기간·선생님 선택 → 날짜×선생님마다 1장
- 시간표 → `인쇄` → 주간 전체(가로 1장) / 요일별 / 선생님별
- 인쇄 창에서 "PDF로 저장"을 고르면 PDF 파일로도 보관할 수 있습니다.

**백업 (월 1회 권장)**
관리 → `업무일지 엑셀 (월별)` 로 지난달 일지 내려받기, 가끔 `전체 백업 파일(JSON)`도 보관.

## 새 학기 엑셀에서 다시 가져오기

```bash
python tools/import_excel.py "시간표.xlsx" "업무일지.xlsx" --sheet 260830
```
→ `supabase/seed.sql` 생성 → Supabase SQL Editor에서 실행.
⚠ `seed.sql`은 **기존 학생·시간표·업무일지를 모두 지우고** 새로 넣습니다. 운영 중에는 앱 화면에서 수정하세요.

## 로컬에서 미리보기 (데모 모드)

`js/config.js`가 비어 있으면 데모 모드로 동작합니다(이 브라우저에만 저장, 테스트용).
```bash
python tools/dev_server.py
```
→ <http://localhost:8765> 접속 → `admin` / `today1234`

## 보안 메모

- 모든 테이블은 직접 접근이 막혀 있고(RLS), 로그인 토큰을 검사하는 `api_*` 함수로만 읽고 씁니다.
- 비밀번호는 bcrypt로 암호화 저장, 로그인 세션은 14일(사용할 때마다 연장).
- 선생님 계정에는 학생 연락처·메모가 전달되지 않습니다.
- 검색엔진 노출 차단(`noindex`). 그래도 주소는 공개 웹이므로 비밀번호 관리에 유의하세요.
- 비용: GitHub Pages, Supabase 모두 무료 플랜 범위(DB 500MB — 이 규모면 수십 년 분량)입니다.
